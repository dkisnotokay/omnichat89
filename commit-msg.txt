Add Twitch GIF support, Kick Kicks gifts and auto-update

Twitch GIFs (platform feature since July 2026):
- Parse the IRC gifs tag (start-end|gifID|gifURL), render as an image in both
  the app and the OBS overlay (larger than an emote, on its own line)
- TTS always strips GIFs: their text is a placeholder like [X GIF by Y]
- Unit tests cover the documented sample, malformed tags and emote+GIF ordering

Kick Kicks gifts (new monetization, akin to Twitch bits):
- Handle the KicksGifted event: shown as a system message with the sender,
  gift name, amount and the viewer's optional attached message
- Subscribe to the broadcaster channel channel_{id} - monetization and goal
  events are never delivered to the chatroom channel, so they were invisible
- fetch_chatroom_id now also returns channel_id
- Explicitly ignore GoalProgressUpdateEvent / KicksLeaderboardUpdated (UI-only)

Auto-update:
- tauri-plugin-updater + process plugin, minisign-signed updates served from
  latest.json in GitHub Releases
- Silent check 5s after startup, banner with download progress, auto restart
- Manual "Check for updates" button in the settings footer
- Release process and latest.json generator documented in docs/

Bump version to 0.3.0
